# RP-001 — Rockefeller Methodology Reconstruction

Research Principle: Every published value must be traceable to an official source, independently reproducible where possible, and accompanied by a documented explanation of any remaining discrepancy.

Purpose: Reconstruct the Rockefeller Institute federal receipts and expenditures methodology for Washington State, with special attention to 2020–2021 COVID-related spending.

Initial target:
- Washington State
- Federal fiscal years 2020 and 2021
- Separate actual federal expenditures from non-COVID structural expenditures

## Research Standard: Complete Numerical Citations

Every numerical value used in this project must be traceable to a cited source.

For every number, record:
- Citation ID
- Source document or dataset
- Page, table, field, or query
- Original value
- Transformation or allocation method
- Reproduced value
- Confidence rating
- Notes on unresolved discrepancies

Project rule: No unexplained numbers.
