# DQ-001 — Lewiston Geography Conflict

**Project:** Washington County Federal Fiscal Balance Project
**Evidence ID:** DQ-001
**Title:** Lewiston Geography Conflict in USAspending Assistance Transactions
**Status:** Confirmed Source Data Inconsistency
**Date:** August 2026

---

# Executive Summary

During certification of the AP-001A Certified Assistance Analytical Ledger, nine USAspending Assistance transactions were identified that contain internally inconsistent geographic information.

Each transaction reports:

* **State Code:** WA
* **State FIPS:** 53 (Washington)

while simultaneously reporting:

* **City:** Lewiston
* **ZIP Code:** 83501

The combination of city "Lewiston" and ZIP Code "83501" is inconsistent with the reported Washington state designation. Because the source record contains conflicting geographic information, no Washington county can be assigned with confidence.

Rather than altering or overriding the source data, the warehouse preserves the records exactly as received and classifies them as a documented geography conflict.

---

# Discovery

The discrepancy was discovered during AP-001A certification while validating county attribution within the certified national Assistance transaction ledger.

Initial validation produced the following summary:

* Total certified transaction rows: **1,025,644**
* Transactions with resolved Washington county: **976,185**
* Washington Unspecified transactions: **49,450**
* Remaining unresolved county assignments: **9**

Investigation determined that all nine unresolved records shared an identical geographic pattern.

# Root Cause Assessment

The warehouse normalization process functioned as designed.

The place normalization logic successfully preserved:

* state designation,
* city,
* ZIP code,
* source fingerprint,
* and transaction provenance.

The inconsistency originates in the source geographic attributes rather than in warehouse processing.

No evidence was found that the ETL process introduced or altered the conflicting values.

---

# Warehouse Policy

The Washington County Federal Fiscal Balance Project follows the principle:

> **Preserve uncertainty rather than manufacture precision.**

Accordingly:

* the transactions remain in the certified national ledger;
* the original geographic values are preserved without modification;
* no Washington county is assigned;
* no Idaho county is assigned;
* no inferred correction is performed.

These transactions shall instead receive the source-condition classification:

```
GEOGRAPHY_CONFLICT
```

The specific conflict subtype for this incident is:

```
STATE_ZIP_CONFLICT
```

---

# Analytical Treatment

These transactions shall:

* remain included in national Assistance totals;
* remain fully traceable to their original USAspending records;
* be excluded from Washington county allocations;
* be reported separately within data quality statistics when appropriate.

No financial adjustments shall be made.
