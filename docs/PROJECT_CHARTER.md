Washington County Federal Fiscal Balance Project
Mission

To build the first fully transparent, independently reproducible implementation of the Rockefeller Institute's federal balance-of-payments methodology using official public federal data, beginning with Washington State and extending to every Washington county wherever the underlying data permit.

Guiding Principles
Measure first. Explain later.
Every published number must be reproducible.
Every transformation must be documented.
Every source must be cited.
Every validation must be automated.
Observed values are never mixed with estimates without explicit labeling.
Every methodological deviation from the Rockefeller Institute's published approach is documented and justified.
The repository should be understandable by someone who has never met its authors.
When evidence and expectations conflict, the evidence takes precedence.
The software should remain reusable for other states and future years.
